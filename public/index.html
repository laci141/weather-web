⛅ Weather

Live forecast, 85 years of history, and bulk data export. Open-Meteo, keyless.

🔓 No API key needed — and none is shared. Every panel reads from Open-Meteo, which is free and keyless for non-commercial use: no sign-up, no account, no personal key in this page. The only ceiling is Open-Meteo's fair-use limit (about 10,000 requests a day). If you want your own quota, you can run this site yourself — the source is on GitHub.

🌡️ Climate Anomaly

Compares one year against a reference period, month by month — temperature and precipitation in separate tables. The default reference is 1991–2020, the WMO's current 30-year normal, but any period from 1940 on works.
